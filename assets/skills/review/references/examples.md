# Review Examples

## Bad
- Skipping review before committing multi-file refactors.
- Asking reviewer to rewrite entire files instead of citing exact line numbers.

## Good
- Run `git diff`, delegate to Code Reviewer, receive line-number citations, patch boundary bug, re-verify.
- The reviewer sees a shallow wrapper in a task diff and demands a new port; with one adapter, that is speculative.
- An architecture pass proposes interfaces before the survey has candidates; survey first, interfaces later.
